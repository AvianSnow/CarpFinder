# Class feats through level 5

Imported through level 5 from remaster Carpfinder books under the ORC license (Player Core, Player Core 2, and later ORC books).
Each class has its own folder. A feat that more than one class can take is copied into each of those folders.
The level 1, 2, and 4 class feat buttons list the chosen class. A level 5 ancestry feat has its own button. Characters spawn at level 1 and receive the later feat when they reach that level.
A chosen feat trains its skills on the character sheet, including a named Lore. A land Speed bonus applies when the feat is gained.
Anything else says: This feature will be implemented later.
